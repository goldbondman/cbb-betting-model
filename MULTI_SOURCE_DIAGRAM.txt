  📊 Conflict logged for review
  🏷️  Source attribution: merged:espn+ncaa+henry

Failure Handling:

Scenario 1: ESPN works, NCAA and Henry fail
  ✅ Uses ESPN data
  ⚠️  Reports failed sources
  ✓  System continues

Scenario 2: All sources fail
  ❌ No data available
  📝 Logs all errors
  ⚠️  Returns empty result with report

Scenario 3: Partial data from each source
  ✅ Merges data from all sources
  📊 Fills missing fields
  ✓  Maximizes completeness
