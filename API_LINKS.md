# API Links Used in This Project

- ESPN Men's College Basketball API (scoreboard, summary, team injuries)
  - https://site.api.espn.com/apis/site/v2/sports/basketball/mens-college-basketball/scoreboard
  - https://site.api.espn.com/apis/site/v2/sports/basketball/mens-college-basketball/summary?event={event_id}
  - https://site.api.espn.com/apis/site/v2/sports/basketball/mens-college-basketball/teams/{team_id}

- NCAA Casablanca API proxy
  - https://ncaa-api.henrygd.me/openapi
  - https://ncaa-api.henrygd.me/casablanca/scoreboard/basketball-men/d1/{year}/{month}/{day}/scoreboard.json
  - https://ncaa-api.henrygd.me/casablanca/game/{game_id}/boxscore.json

- Barttorvik data endpoints
  - https://barttorvik.com/teamstats.php?year={year}&conlimit=Sum&csv=1
  - https://barttorvik.com/{year}_fffinal.csv
  - https://barttorvik.com/getadvstats.php?year={year}&csv=1
  - https://barttorvik.com/{year}_team_results.csv

- HaslaMetrics ratings endpoint
  - https://haslametrics.com/ratings.php

- Supabase API / platform docs (used for database and storage integration)
  - https://supabase.com/docs/reference
